# Author voice profile schema

Use this structure for the canonical Markdown profile. Omit empty sections rather than filling them with guesses.

## Profile metadata

- Generated and last refreshed timestamps
- Profile version
- Canonical profile path
- Corpus word count or a clearly labeled estimate
- Overall confidence: provisional, moderate, or strong
- Known limitations, including coauthorship or mixed genres

## Source index

For each source record:

- Google Drive file ID
- Title and MIME type
- Last modified time
- Genre
- Approximate analyzed word count
- Inclusion confidence and any provenance caveat

Do not reproduce full documents.

## Quantitative baseline

Report only statistics that can be supported by the available text:

- Typical and observed sentence-length range
- Typical paragraph length
- Frequency or qualitative level of first person, passive voice, hedges, questions, parentheticals, semicolons, colons, and em dashes
- Common transition types

Use medians and ranges when practical. Label estimates.

## Stable voice

Describe recurring patterns in:

- Argument sequencing
- Sentence rhythm and syntactic complexity
- Degree of directness and qualification
- Preferred terminology and verbs
- Citation integration
- Presentation of assumptions, limitations, and causal claims
- Interpretation of tables, estimates, and robustness checks
- Openings, section transitions, and conclusions

For each material characteristic include:

1. The observation.
2. Confidence and supporting sources.
3. One short excerpt or paraphrased example.
4. An actionable implication for future editing.

## Genre variants

Create subsections only for genres represented by enough evidence, such as economics papers, research proposals, motivation letters, or professional correspondence. Explain how each differs from the stable voice.

## Editing guidance

### Preserve

List distinctive, effective habits that an editor should retain.

### Prefer

List choices supported by the corpus, phrased as tendencies rather than absolute rules.

### Avoid or verify

List patterns that would create a conspicuous mismatch. Explain whether each is absent from the corpus, contradicted by it, or merely uncertain.

## Evidence discipline

- Do not infer personality, identity, demographic traits, or authorship.
- Do not elevate a single phrase into a stable rule.
- Distinguish the user's prose from quotations and copied institutional language.
- Keep excerpts short and use them only to support concrete observations.
- Treat the profile as editorial evidence, not a biometric signature.
